# NTRL Website

A professional corporate website developed for **Nirvan Testing & Research Laboratory Pvt. Ltd. (NTRL)**, a testing and research laboratory based in Patna, Bihar.

The website focuses on presenting NTRL's testing services, technical capabilities, certifications, project experience and laboratory facilities in a clean, modern and professional manner.

## Features

* Responsive corporate website
* Professional engineering-focused design
* Testing and research service sections
* NABL accreditation and ISO 9001:2015 sections
* Project and client showcase
* Laboratory and equipment gallery
* Testing enquiry form
* Contact and quotation sections
* Mobile-friendly navigation
* SEO-friendly page structure

## Tech Stack

* React.js
* TypeScript
* Tailwind CSS
* Vite
* Lucide React

## Pages

* Home
* About Us
* Services
* Industries
* Projects
* Certifications
* Gallery
* Clients
* Contact Us

## Development

Run the project locally with:

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

## Note

The website content and company credentials are based on information provided by NTRL. Unavailable information is kept as placeholders and can be updated when the official details are provided.
